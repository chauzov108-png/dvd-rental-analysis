# Анализ базы данных DVD Rental: SQL + Python

## Цель проекта

Проанализировать выручку, клиентов, категории и фильмы на основе данных PostgreSQL.

## Использованные инструменты

- PostgreSQL
- pgAdmin
- SQL
- Python
- Pandas
- Matplotlib
- Google Colab

## Выполненные задачи

- анализ выручки по месяцам;
- сравнение выручки магазинов;
- анализ количества клиентов по магазинам;
- расчёт выручки на одного клиента;
- определение популярных категорий;
- поиск наиболее доходных фильмов;
- расчёт среднего платежа;
- поиск клиента с максимальной суммой платежей;
- выявление редко арендуемых и ни разу не арендованных фильмов.

## Итоги анализа

Данные охватывают период с 14 февраля по 14 мая 2007 года. Поскольку февраль и май представлены не полностью, корректнее сравнивать между собой полные месяцы — март и апрель. Выручка выросла с 23,9 тыс. в марте до 28,6 тыс. в апреле.

Выручка двух магазинов находится примерно на одном уровне. Магазин №2 получил 31,1 тыс., а магазин №1 — 30,3 тыс. При этом у магазина №1 больше клиентов: 326 против 273.

Выручка на одного клиента выше у магазина №2 — 113,77 против 92,80, что объясняет его более высокий общий результат при меньшем количестве клиентов.

Наиболее популярными категориями стали Sports, Animation и Action. Самым доходным фильмом оказался Telegraph Voyage с выручкой 216.

Средний размер одного платежа составил 4,20. Наибольшую общую сумму платежей внесла Eleanor, клиент №148, — 211,55.

Реже всего арендовали Train Bunch, Mixed Doors и Hardly Robbers — по 4 раза. Кроме того, 43 фильма ни разу не были арендованы.

## Основные выводы

- магазины имеют сопоставимую общую выручку;
- магазин №1 привлекает больше клиентов;
- магазин №2 получает больше выручки на одного клиента;
- часть фильмов имеет очень низкий или нулевой спрос;
- фильмы без аренд требуют дополнительной проверки.
